# Карта экранов: чистый текст для отрисовки

Семь колонок в порядке флоу «Онбординг». Каждый экран — своя колонка, даже с одним состоянием. Один экран — одна колонка: шит над экраном и состояние с другим наполнением — карточки той же колонки. Колонка — экран; карточка — состояние экрана. Между колонками стрелки только основного пути вперёд (таблица в конце). «Общий» — экран используется и вне онбординга. В строке «→» только куда ведёт главное действие; если действие остаётся на экране, строки нет. «Назад» без пометки — туда, откуда пришёл.

Статус карточки — данные для значка готовности макета (Есть · Частично · Нет → Дизайн · Решено → Дизайн · Правило): Есть — галочка; Нет → Дизайн и Решено → Дизайн — крестик; Частично — «в работе»; Правило — без значка. На самой карточке на макете статус словами не выводится.

---

## Приветствие

**Приветствие**
Видит: две кнопки «Продолжить» и «Пропустить»; анимация проигрывается обязательно.
→ Выбор целей
Статус: Нет → Дизайн

---

## Выбор целей

**Выбор целей**
Видит: цели на выбор, выбрать можно несколько, счётчик выбранных.
→ Рекомендация страны
Назад: Приветствие, анимация запуска не повторяется
Статус: Нет → Дизайн

**Выбрано три цели**
Видит: остальные цели неактивны, выбранную можно снять.
Статус: Решено → Дизайн

**Загрузка**
Видит: список целей ещё не пришёл.
Статус: Нет → Дизайн

**Ошибка**
Видит: список целей получить не удалось.
Статус: Нет → Дизайн

---

## Рекомендация страны

**Рекомендация страны**
Видит: рекомендованная страна наверху, видны совпавшие цели, ниже остальные страны.
→ Детали страны
Статус: Нет → Дизайн

**Загрузка**
Видит: рекомендации ещё не пришли.
Статус: Нет → Дизайн

**Ошибка**
Видит: рекомендации получить не удалось.
Статус: Нет → Дизайн

---

## Детали страны
Общий. Откуда: с главной и из локаций

**Страна не куплена**
Видит: данные страны, характеристики, включённые устройства, кнопка покупки.
→ Детали заказа
Статус: Есть

**Выбор срока**
Видит: срок доступа и цена за него, кнопка оформления; поверх экрана.
→ Детали заказа
Статус: Есть

**Страна сейчас не работает**
Видит: предупреждение, что страна на технических работах; оплату оно не блокирует.
→ Детали заказа
Статус: Нет → Дизайн

**Нет устройств**
Видит: страна куплена, список устройств пустой, кнопка подключения.
→ создание устройства
Статус: Есть

**Есть место**
Видит: список устройств, новое — первым, статус «активен сейчас».
Статус: Есть

**Лимит устройств**
Видит: заняты все разрешённые устройства, можно увеличить лимит.
→ Доп. слоты
Статус: Есть

**Технические работы**
Видит: уведомление о технических работах, страна не в сети.
Статус: Есть

---

## Детали заказа
Общий. Откуда: при продлении купленной страны

**Детали заказа**
Видит: состав заказа, срок, дополнительные устройства, способ оплаты.
→ Статус заказа
Статус: Есть

**Бонусный баланс**
Видит: бонусный баланс и пояснение, что это такое.
Статус: Есть

**Выбор платёжного сервиса**
Видит: список платёжных сервисов поверх экрана.
→ платёжный сервис
Статус: Есть

**Заказ оформляется**
Видит: заказ создаётся после выбора платёжного сервиса.
→ платёжный сервис
Статус: Нет → Дизайн

---

## Статус заказа
Общий. Откуда: после оплаты и из истории

**Ожидает оплаты**
Видит: отсчёт времени на оплату и кнопка «Продолжить оплату».
→ платёжный сервис
Статус: Есть

**Загрузка**
Видит: данные заказа ещё приходят.
Статус: Есть

**В обработке**
Видит: «оплата получена, заказ обрабатывается», индикатор, кнопка обращения в поддержку.
Статус: Есть

**Оплата прошла**
Видит: чек, срок, сумма, способ оплаты; кнопки «Подключиться» и «Пропустить».
→ Устройство создано
Назад: шит отмены онбординга
Статус: Частично

**Оплата прошла, страна уже подключена**
Видит: то же, но кнопки «Подключиться» нет.
Статус: Правило

**Время на оплату вышло**
Видит: время на оплату вышло, заказ отменён.
→ Выбор целей
Статус: Решено → Дизайн

**Оплата не прошла**
Видит: ничего нового; причину показывает платёжный сервис.
→ Выбор целей
Статус: Правило

**Подтверждение отмены**
Видит: шит «Вернуться назад?» и «Если сейчас вернуться назад, то заказ отменится и подбор страны будет начат заново»; кнопки «Подтвердить» и «Отмена».
→ Выбор целей
Статус: Решено → Дизайн

**Отмена онбординга**
Видит: шит при нажатии «Назад», в нём кнопка «Пропустить»; текст пишет автор.
→ Главная
Статус: Нет → Дизайн

---

## Устройство создано

**Устройство создано**
Видит: имя и платформа нового устройства, дальше получение файла.
→ Детали страны
Статус: Частично

**Не создалось**
Видит: устройство не создалось.
Статус: Нет → Дизайн

---

## Стрелки между колонками

**Рисуются** (основной путь вперёд, между соседними колонками).

| Из | В | Подпись |
|---|---|---|
| Приветствие | Выбор целей | начинает подбор |
| Выбор целей | Рекомендация страны | выбирает, что нужно |
| Рекомендация страны | Детали страны | выбирает рекомендованную страну |
| Детали страны | Детали заказа | выбирает срок доступа |
| Детали заказа | Статус заказа | выбирает платёжный сервис |
| Статус заказа | Устройство создано | подключает устройство |

**Не рисуются** (ветки, возвраты и выходы по флоу; на карте не показываются).

| Из | В | Подпись |
|---|---|---|
| Приветствие | Главная | пропустил обучение |
| Рекомендация страны | Детали страны | смотрит остальные и выбирает другую страну |
| Рекомендация страны | выход | уходит |
| Детали страны | Детали заказа | оформляет, активация позже |
| Детали страны | Рекомендация страны | возвращается к выбору |
| Статус заказа | Подтверждение отмены | возвращается назад |
| Подтверждение отмены | Выбор целей | подтверждает |
| Подтверждение отмены | Статус заказа | остаётся |
| Статус заказа | Оплата прошла (внутри колонки) | оплачена |
| Статус заказа | Выбор целей | не прошла или время вышло: возвращается к подбору |
| Статус заказа | выход | не платил: уходит |
| Статус заказа | выход | нет доступа: грустно уходит |
| Статус заказа | выход | нет доступа: пишет в поддержку |
| Статус заказа | Главная | пропускает создание |
| Устройство создано | Детали страны | возвращается к стране |
| Детали страны | проверка работы | проверяет на работоспособность |
