# Карта экранов: чистый текст для отрисовки

Девять колонок в порядке флоу «Онбординг». Колонка — экран; карточка — состояние экрана. Между колонками — стрелки с действием пользователя. «Общий» — экран используется и вне онбординга. «Назад» — туда, откуда пришёл, если не сказано иначе.

Статус карточки — данные для значка готовности макета (Есть · Частично · Нет → Дизайн · Решено → Дизайн · Правило). На самой карточке на макете он словами не выводится: вместо него значок и его цвет (ЖР §127).

---

## Выбор целей
Откуда: Приветствие; возврат после отмены заказа или неоплаты

**Основной**
Видит: цели на выбор, выбрать можно несколько; счётчик выбранных.
→ Рекомендация страны; назад — Приветствие, анимация запуска не повторяется
Нет → Дизайн

**Выбрано три цели**
Видит: остальные цели неактивны, выбранную можно снять.
→ тот же экран
Решено → Дизайн

**Загрузка**
Видит: список целей ещё не пришёл.
→ тот же экран
Нет → Дизайн

**Ошибка**
Видит: список целей получить не удалось.
→ тот же экран
Нет → Дизайн

---

## Рекомендация страны
Откуда: Выбор целей; возврат от страны, которая сейчас не работает

**Основной**
Видит: рекомендованная страна наверху, видны совпавшие цели; ниже остальные страны.
→ Детали страны; назад — Выбор целей
Нет → Дизайн

**Загрузка**
Видит: рекомендации ещё не пришли.
→ тот же экран
Нет → Дизайн

**Ошибка**
Видит: рекомендации получить не удалось.
→ тот же экран
Нет → Дизайн

---

## Детали страны
Общий. Откуда: Рекомендация страны, Главная, Локации

**Страна не куплена**
Видит: данные страны, характеристики, включённые устройства, кнопка покупки.
→ Детали заказа; назад — туда, откуда пришёл
Есть

**Выбор срока**
Видит: срок доступа и цена за него, кнопка оформления; поверх экрана.
→ Детали заказа
Есть

**Страна сейчас не работает**
Видит: предупреждение, что страна на технических работах; оплату оно не блокирует.
→ Детали заказа или Рекомендация страны
Нет → Дизайн

---

## Детали заказа
Общий. Откуда: Детали страны; продление купленной страны

**Основной**
Видит: состав заказа, срок, дополнительные устройства, способ оплаты.
→ Статус заказа; назад — Детали страны
Есть

**Бонусный баланс**
Видит: бонусный баланс и пояснение, что это такое.
→ тот же экран
Есть

**Выбор платёжного сервиса**
Видит: список платёжных сервисов поверх экрана.
→ оплата у сервиса, затем Статус заказа
Есть

**Заказ оформляется**
Видит: заказ создаётся после выбора платёжного сервиса.
→ оплата у сервиса
Нет → Дизайн

---

## Статус заказа
Общий. Откуда: платёжный сервис после оплаты; История

**Ожидает оплаты**
Видит: отсчёт времени на оплату и кнопка «Продолжить оплату».
→ оплата у сервиса; назад — Подтверждение отмены
Есть

**Загрузка**
Видит: данные заказа ещё приходят.
→ Ожидает оплаты
Есть

**В обработке**
Видит: «оплата получена, заказ обрабатывается», индикатор, кнопка обращения в поддержку.
→ Оплачено
Есть

**Оплачено**
Видит: оплата прошла.
→ Оплата прошла
Есть

**Время на оплату вышло**
Видит: время на оплату вышло, заказ отменён.
→ назад — Выбор целей
Решено → Дизайн

**Оплата не прошла**
Видит: ничего нового; причину показывает платёжный сервис.
→ Выбор целей
Правило

---

## Подтверждение отмены
Шит над экраном. Откуда: Статус заказа, «Назад»

**Основной**
Видит: «Вернуться назад?» и «Если сейчас вернуться назад, то заказ отменится и подбор страны будет начат заново»; кнопки «Подтвердить» и «Отмена».
→ «Подтвердить» — Выбор целей; «Отмена» — Статус заказа
Решено → Дизайн

---

## Оплата прошла
Откуда: Статус заказа

**Страна без устройств**
Видит: чек, срок, сумма, способ оплаты; кнопка «Подключиться».
→ создание устройства; «Пропустить» — Главная
Частично

**Страна уже подключена**
Видит: то же, но кнопки «Подключиться» нет.
→ —
Правило

**Отмена онбординга**
Видит: шит при нажатии «Назад», в нём кнопка «Пропустить»; текст пишет автор.
→ «Пропустить» — Главная; отказ — остаётся на экране
Нет → Дизайн

---

## Устройство создано
Откуда: создание устройства

**Основной**
Видит: имя и платформа нового устройства; дальше получение файла.
→ проверка работы; Купленная страна
Частично

**Не создалось**
Видит: устройство не создалось; можно уйти или написать в поддержку.
→ уходит; поддержка
Нет → Дизайн

---

## Купленная страна
Общий. Откуда: Устройство создано, Главная, Локации

**Нет устройств**
Видит: пустой список устройств, кнопка подключения.
→ создание устройства; назад — туда, откуда пришёл
Есть

**Есть место**
Видит: список устройств, новое — первым, статус «активен сейчас».
→ проверка работы
Есть

**Лимит устройств**
Видит: заняты все разрешённые устройства, можно увеличить лимит.
→ Доп. слоты
Есть

**Технические работы**
Видит: уведомление о технических работах, страна не в сети.
→ тот же экран
Есть

## Стрелки между колонками

Из какого экрана в какой — подпись (действие пользователя, как в флоу).

| Из | В | Подпись |
|---|---|---|
| Выбор целей | Рекомендация страны | выбирает, что нужно |
| Рекомендация страны | Детали страны | выбирает рекомендованную страну |
| Рекомендация страны | Детали страны | смотрит остальные и выбирает другую страну |
| Рекомендация страны | выход | уходит |
| Детали страны | Детали заказа | выбирает срок доступа |
| Детали страны | Детали заказа | оформляет, активация позже |
| Детали страны | Рекомендация страны | возвращается к выбору |
| Детали заказа | Статус заказа | выбирает платёжный сервис |
| Статус заказа | Подтверждение отмены | возвращается назад |
| Подтверждение отмены | Выбор целей | подтверждает |
| Подтверждение отмены | Статус заказа | остаётся |
| Статус заказа | Оплата прошла | оплачена |
| Статус заказа | Выбор целей | не прошла или время вышло: возвращается к подбору |
| Статус заказа | выход | не платил: уходит |
| Статус заказа | выход | нет доступа: грустно уходит |
| Статус заказа | выход | нет доступа: пишет в поддержку |
| Оплата прошла | Устройство создано | подключает устройство |
| Оплата прошла | Главная | пропускает создание |
| Устройство создано | Купленная страна | возвращается к стране |
| Устройство создано | проверка работы | проверяет на работоспособность |
| Купленная страна | проверка работы | проверяет на работоспособность |
