# Сессии по ролям из SESSION_STARTERS.md

## Формат файла

`SESSION_STARTERS.md` лежит в корне проекта:

```markdown
# Стартовые сообщения сессий <Проект>

## Общая шапка (в начало каждого)
— Проект: <название>, папка `<путь>`, прототип/сайт <url>.
— Правила работы: читай `AGENTS.md` / `CLAUDE.md` / `MEMORY.md` в начале.
— Сейчас задача: <текущая цель>.
— Запрос не по твоей роли не выполняй, назови нужную сессию и предложи переслать.

## <Роль 1>
<2–5 предложений: что делает, чего не делает, кому отчитывается>

## <Роль 2>
...
```

Блок, чьё название начинается с «Общая шапка», не роль, а префикс ко всем остальным. Все остальные блоки `## ` — роли.

## Порядок

1. Найди файл: сначала рабочая папка, потом `git fetch` и все ветки (`git ls-tree -r --name-only origin/<branch>`). Нет файла — скажи об этом и предложи создать по шаблону выше; не выдумывай роли.
2. Разбери блоки. Текст каждого блока бери **дословно**, без пересказа. Первое сообщение сессии = шапка + пустая строка + `## <Роль>` + текст блока.
3. Создай сессии, по одной на роль:
   - **Есть `create_session`** (облако, claude-code-remote) — создай настоящие сессии: `title` = название роли, `source_url` = remote репозитория (`git remote get-url origin`), `prompt` = текст из п.2, `tags` = [имя проекта]. Создавай все параллельно.
   - **Нет `create_session`, есть `spawn_task`** — карточки задач, которые пользователь запускает в один клик.
   - **Ничего нет** — выведи готовые тексты по одному в блоке кода для копирования.
   Если пользователь просит «сессии», а ты сделал карточки и потом создаёшь сессии — убери карточки (`dismiss_task`), чтобы не было дублей.
4. Отчитайся таблицей: роль → id сессии. Отдельно — что в облаке не сработает:
   - локальные пути из шапки (`C:\...`, `~/...`) в облаке не существуют, там клон репозитория;
   - локальная память (`MEMORY.md` вне репозитория) облаку недоступна;
   - коннекторы/хосты, заблокированные сетевой политикой окружения;
   - файлы, не закоммиченные и не запушенные, пропадают вместе с контейнером.

## Правила

- Не меняй тексты ролей и не добавляй роли от себя.
- Не создавай повторно уже существующие сессии с теми же названиями — сначала проверь `list_sessions`, если он есть, и спроси.
