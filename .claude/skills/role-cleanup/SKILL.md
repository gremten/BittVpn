# Оптимизация

## Ревизия

Собери отчёт, ничего не удаляя:

```bash
# самые тяжёлые файлы, отслеживаемые git
git ls-files -z | xargs -0 du -k 2>/dev/null | sort -rn | head -30
# подозрительные имена: копии, версии, черновики
git ls-files | grep -iE '(copy|копия|old|backup|_v[0-9]+|draft|tmp|temp|test[0-9]*)\.'
# неотслеживаемый мусор
git status --porcelain --ignored | head -50
```

Для ассетов проверь, используются ли они: `git grep -l "<имя файла>"` — нет ссылок = кандидат.

Для каждого кандидата: путь, вес, почему мусор (дубль чего / нет ссылок / одноразовый), что предлагаешь (удалить / сжать / перенести).

## Чистка

- **Перед любым удалением показываешь автору список и ждёшь «да».**
- Архивы, `backup*`, `archive*` и подобное не трогаешь без прямой просьбы, даже если они тяжёлые — только упоминаешь в отчёте.
- Сжатие ассетов — без видимой потери: сравни до/после, укажи экономию в КБ.
- Удаляй через `git rm`, одним понятным коммитом на группу.

## Куда класть своё

- Свои md-отчёты — в папку `оптимизация/` (или как назначено в проекте).
- Скрипты, полезные в будущем, — в `tools/`, с короткой шапкой-комментарием: что делает и как запускать. Одноразовые скрипты — в scratchpad, не в репозиторий.
