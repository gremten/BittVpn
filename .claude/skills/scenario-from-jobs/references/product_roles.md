Готовит «Исследование», 2026-11-15, по решению автора: общий список ролей продукта согласован; сценарий показывает у себя те роли из списка, которые в нём участвуют, дословно. Формулировки дословно из сценариев автора (Figma, тексты в репозитории), ничего не переписано. **Уточнение автора (2026-11-15):** блок «Роли» остаётся внутри каждого сценария, но берёт только роли из этого общего списка, новых своих ролей сценарий не вводит; формулировка роли одна и та же везде. Figma не менялась. Где список будет жить в Figma, решит автор (вопрос 3).

Источники: сценарий онбординга (эталон, `research/etalon_figma_copy_texts.md`, раздел «а»); сценарий «Доступ к выбранной стране» (`research/scenarios_texts_dostup_k_vybrannoj_strane.md`, версия из Figma). ## 2. Две версии формулировок (ждёт слова автора)

Формулировки одних и тех же ролей в двух сценариях не совпадают. Автор не определился с главной («хз»): **остаётся как есть в каждом сценарии**, обе версии зафиксированы выше. Статус: **ждёт слова автора**; к вопросу сам не возвращаюсь.
- «Новый пользователь»: в онбординге «…и не знает, чем варианты отличаются», в покупке «…и не знает, из чего складывается сумма и кому он платит». Начало: «Пользователь, который впервые пользуется…» (онбординг) и «Впервые платит…» (покупка).
- «Опытный пользователь» и «Релокант»: смысл совпадает, отличается начало «Пользователь, который…».

## 3. Решения автора (2026-11-15)

1. Блок «Роли» внутри каждого сценария, роли только из общего списка; роль в сценарии показывается названием и формулировкой, без ссылок на список.
2. Список живёт только в репозитории, в Figma не заводится.
3. Роль «Покупает для близких» остаётся в списке, в «Доступ к выбранной стране» не нужна.
4. «Релокант» — роль; тест «роль / опция» к нему не применяется.
5. Единая формулировка роли пока не выбрана («как есть в каждом сценарии»).
