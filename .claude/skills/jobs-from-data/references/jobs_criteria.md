## 2. Устройство эталона 7685:2

- Карточка одной фичи/сценария: заголовок «Первый вход» и четыре блока в этом порядке: **Core, Trigger, Outcome, Risk-Reduction**. Статусов, номеров, ссылок нет.
- Core — одна фраза «Когда я впервые открываю VPN, я хочу …, чтобы …».
- Trigger — 6 строк «Когда …». Outcome — 4 строки «Я хочу …». Risk-Reduction — 9 строк «Я не хочу …».
- Строки без точки в конце. Всё от первого лица.
- Коды живут вне карточки: в гипотезах «Из джобов» пишет «Core», «T1», «O2», «R6» и т. д. Код = порядковый номер строки в блоке. Проверила: все ссылки R1–R9, T1, T6, O1–O4 в гипотезах эталона совпадают с порядком строк.
- Оформление: Martian Grotesk 20 (заголовок), Golos UI Medium 16 (метки), Golos UI Regular 16 (текст); заливки #f3f3f3; одна рамка 512×1504, 29 фреймов с auto-layout; инстансов и связей нет.

## 3. Критерии

Ответ по каждому критерию: ок / частично / нет / не проверено. Для каждого «нет» и «частично» — «было → стало → почему» как предложение, не как правка. **Эталон 7685:2 проходит все критерии без вопросов** (автор, 2026-11-15: «все как в Фигме есть так и правильно»).

### Блокирующие (Д1–Д11)

| № | Критерий | Основание |
|---|---|---|
| Д1 | **Структура.** Заголовок и четыре блока Core / Trigger / Outcome / Risk-Reduction в этом порядке; внутри нет статусов, номеров, кодов, служебных пометок, ссылок на журнал | автор (эталон 7685:2); правка автора «статусы и номера не выводятся» (`etalon_figma_copy_nodes.md`) |
| Д2 | **Core — одна работа с результатом.** Одна фраза «Когда [ситуация], я хочу [прогресс], чтобы [результат]». «Чтобы» не пропущено и не повторяет действие | автор: §44 («чтобы» вернули, вопрос про две работы закрыт); правило процесса §8.2 |
| Д3 | **В Core нет решения продукта и действия-механики.** Не «купить», не «подключить», не названия шагов; Core описывает, что человек получит | правило процесса §8.2 («не купить, а пользоваться»); автор убрал «купить доступ» и «сразу подключить» (ред. 5, §44) |
| Д4 | **Trigger — ситуация, не функция и не решение.** Каждая строка начинается с «Когда», в строке одна ситуация (разные каналы разнесены по строкам) | правило процесса §8.2; автор разнёс «друг / нашёл сам» на отдельные строки |
| Д5 | **Outcome — отдельная строка «Я хочу …», не повторяет Core слово в слово и не склеивает несколько отдельных результатов в одну строку** | автор: отверг Outcome ред. 2 за повтор Core и три действия в одной строке (ред. 3); правило процесса §8.2 |
| Д6 | **Нет языка интерфейса.** Ни в одном блоке нет «кнопка», «экран», названий элементов и компонентов | правило процесса §8.2. Слово «приложение» автор оставил |
| Д7 | **Risk — «Я не хочу …», одна тревога на строку, без дословных дублей** | правило процесса §8.2 |
| Д8 | **Джоб не утверждает того, чего нет в продукте.** Строки не должны опираться на функцию, которой нет (проверка: `research/product_inventory.md`, слова автора). Страх человека, который автор оставил в эталоне, не снимается автоматически | правило процесса §8.2; автор: убрал риск про автосписания «в функционале нет» (ред. 5); ответ автора 2026-11-15: страх про то, чего нет, автоматически не убирать, решать по эталону |
| Д9 | **Не затирать правки автора.** Свежая версия автора и Figma-копия главнее репозитория; убранное автором (риск про непонятный сервис, автосписания, пятый Outcome ред. 4) не возвращать без его слова | автор: §139; `scenario-from-jobs`: «не затирать то, что автор правил руками» |
| Д10 | **Коды стабильны.** Порядок строк = код (T1…, O1…, R1…); вставка или перестановка требует проверки всех «Из джобов» в гипотезах; нет ссылок на несуществующие строки | автор (эталон гипотез: «T1», «R6», «Core» в «Из джобов»); §64 |
| Д11 | **У новых строк есть источник** (автор / пользователь / поддержка / данные / «ИИ, не проверено»). Строки «ИИ, не проверено» не идут дальше (в сценарии, гипотезы), пока автор не подтвердил. Строки эталона и уже утверждённые автором имеют источник «автор» | правило процесса (ЖР §103, `PROCESS_GUIDE.md`, «источник ситуации»); автор: §21 принял триггер про поездку после вопроса |

## 5. Закрытые вопросы автору (2026-11-15)

Ответ автора на все семь: «все как в Фигме есть так и правильно, все тут правильно».

1. Outcome-действия («быстро выбрать страну», «перейти к подключению») — нормально.
