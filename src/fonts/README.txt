nothing-font.otf

MartianGrotesk.woff2

Golos UI
--------
GolosUI-VF.woff2

Golos UI is self-hosted as a local variable font with a 400–700 weight range.
The font file is generated from the original Golos_UI_Complete_Family.zip by:

  npm run font:install

See ../../GOLOS_UI_LOCAL.md for setup details.
