# Карта экранов: чистый текст для отрисовки

Семь колонок в порядке флоу «Онбординг». Один экран — одна колонка: шит над экраном и состояние с другим наполнением — карточки той же колонки. Колонка — экран; карточка — состояние экрана. Между колонками стрелки только основного пути вперёд (таблица в конце). «Общий» — экран используется и вне онбординга. «Назад» без пометки — туда, откуда пришёл.

Статус карточки — данные для значка готовности макета (Есть · Частично · Нет → Дизайн · Решено → Дизайн · Правило). На самой карточке на макете он словами не выводится: вместо него значок и его цвет (ЖР §127).

---

## Выбор целей
Откуда: Приветствие; после отмены заказа или неоплаты

**Основной**
Видит: цели на выбор, выбрать можно несколько; счётчик выбранных.
→ Рекомендация страны
Назад: Приветствие, анимация запуска не повторяется
Статус: Нет → Дизайн

**Выбрано три цели**
Видит: остальные цели неактивны, выбранную можно снять.
→ остаётся на экране
Статус: Решено → Дизайн

**Загрузка**
Видит: список целей ещё не пришёл.
→ остаётся на экране
Статус: Нет → Дизайн

**Ошибка**
Видит: список целей получить не удалось.
→ остаётся на экране
Статус: Нет → Дизайн

---

## Рекомендация страны
Откуда: Выбор целей; Детали страны, если страна сейчас не работает

**Основной**
Видит: рекомендованная страна наверху, видны совпавшие цели; ниже остальные страны.
→ Детали страны
Статус: Нет → Дизайн

**Загрузка**
Видит: рекомендации ещё не пришли.
→ остаётся на экране
Статус: Нет → Дизайн

**Ошибка**
Видит: рекомендации получить не удалось.
→ остаётся на экране
Статус: Нет → Дизайн

---

## Детали страны
Общий. Откуда: Рекомендация страны, Главная, Локации, Устройство создано (возвращение после создания устройства)

**Страна не куплена**
Видит: данные страны, характеристики, включённые устройства, кнопка покупки.
→ Детали заказа
Статус: Есть

**Выбор срока**
Видит: срок доступа и цена за него, кнопка оформления; поверх экрана.
→ Детали заказа
Статус: Есть

**Страна сейчас не работает**
Видит: предупреждение, что страна на технических работах; оплату оно не блокирует.
→ Детали заказа или Рекомендация страны
Статус: Нет → Дизайн

**Нет устройств**
Видит: страна куплена, список устройств пустой, кнопка подключения.
→ создание устройства
Статус: Есть

**Есть место**
Видит: список устройств, новое — первым, статус «активен сейчас».
→ проверка работы
Статус: Есть

**Лимит устройств**
Видит: заняты все разрешённые устройства, можно увеличить лимит.
→ Доп. слоты
Статус: Есть

**Технические работы**
Видит: уведомление о технических работах, страна не в сети.
→ остаётся на экране
Статус: Есть

---

## Детали заказа
Общий. Откуда: Детали страны; продление купленной страны

**Основной**
Видит: состав заказа, срок, дополнительные устройства, способ оплаты.
→ Статус заказа
Статус: Есть

**Бонусный баланс**
Видит: бонусный баланс и пояснение, что это такое.
→ остаётся на экране
Статус: Есть

**Выбор платёжного сервиса**
Видит: список платёжных сервисов поверх экрана.
→ оплата у сервиса
Статус: Есть

**Заказ оформляется**
Видит: заказ создаётся после выбора платёжного сервиса.
→ оплата у сервиса
Статус: Нет → Дизайн

---

## Статус заказа
Общий. Откуда: платёжный сервис после оплаты; История

**Ожидает оплаты**
Видит: отсчёт времени на оплату и кнопка «Продолжить оплату».
→ оплата у сервиса
Назад: Подтверждение отмены
Статус: Есть

**Загрузка**
Видит: данные заказа ещё приходят.
→ Ожидает оплаты
Статус: Есть

**В обработке**
Видит: «оплата получена, заказ обрабатывается», индикатор, кнопка обращения в поддержку.
→ Оплачено
Статус: Есть

**Оплачено**
Видит: оплата прошла.
→ Оплата прошла
Статус: Есть

**Время на оплату вышло**
Видит: время на оплату вышло, заказ отменён.
→ Выбор целей
Статус: Решено → Дизайн

**Оплата не прошла**
Видит: ничего нового; причину показывает платёжный сервис.
→ Выбор целей
Статус: Правило

**Подтверждение отмены**
Видит: шит «Вернуться назад?» и «Если сейчас вернуться назад, то заказ отменится и подбор страны будет начат заново»; кнопки «Подтвердить» и «Отмена».
→ Выбор целей или остаётся на экране
Статус: Решено → Дизайн

---

## Оплата прошла
Откуда: Статус заказа

**Страна без устройств**
Видит: чек, срок, сумма, способ оплаты; кнопки «Подключиться» и «Пропустить».
→ создание устройства или Главная
Назад: шит отмены онбординга
Статус: Частично

**Страна уже подключена**
Видит: то же, но кнопки «Подключиться» нет.
→ —
Статус: Правило

**Отмена онбординга**
Видит: шит при нажатии «Назад», в нём кнопка «Пропустить»; текст пишет автор.
→ Главная или остаётся на экране
Статус: Нет → Дизайн

---

## Устройство создано
Откуда: создание устройства

**Основной**
Видит: имя и платформа нового устройства; дальше получение файла.
→ Детали страны
Статус: Частично

**Не создалось**
Видит: устройство не создалось; можно уйти или написать в поддержку.
→ поддержка или выход
Статус: Нет → Дизайн

## Стрелки между колонками

**Рисуются** (основной путь вперёд, между соседними колонками).

| Из | В | Подпись |
|---|---|---|
| Выбор целей | Рекомендация страны | выбирает, что нужно |
| Рекомендация страны | Детали страны | выбирает рекомендованную страну |
| Детали страны | Детали заказа | выбирает срок доступа |
| Детали заказа | Статус заказа | выбирает платёжный сервис |
| Статус заказа | Оплата прошла | оплачена |
| Оплата прошла | Устройство создано | подключает устройство |

**Не рисуются** (ветки, возвраты и выходы — текст в карточках).

| Из | В | Подпись | Где в карте |
|---|---|---|---|
| Рекомендация страны | Детали страны | смотрит остальные и выбирает другую страну | карточка «Основной» |
| Рекомендация страны | выход | уходит | карточка «Основной» |
| Детали страны | Детали заказа | оформляет, активация позже | карточка «Страна сейчас не работает» |
| Детали страны | Рекомендация страны | возвращается к выбору | карточка «Страна сейчас не работает» |
| Статус заказа | Подтверждение отмены | возвращается назад | карточка «Подтверждение отмены» той же колонки |
| Подтверждение отмены | Выбор целей | подтверждает | карточка «Подтверждение отмены» |
| Подтверждение отмены | Статус заказа | остаётся | карточка «Подтверждение отмены» |
| Статус заказа | Выбор целей | не прошла или время вышло: возвращается к подбору | карточки «Оплата не прошла», «Время на оплату вышло» |
| Статус заказа | выход | не платил: уходит | колонка «Статус заказа» |
| Статус заказа | выход | нет доступа: грустно уходит | колонка «Статус заказа» |
| Статус заказа | выход | нет доступа: пишет в поддержку | карточка «В обработке» |
| Оплата прошла | Главная | пропускает создание | карточка «Страна без устройств» |
| Устройство создано | Детали страны | возвращается к стране | карточка «Устройство создано» |
| Детали страны | проверка работы | проверяет на работоспособность | карточка «Есть место» |
