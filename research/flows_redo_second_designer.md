## 3. Работа: флоу «Выпуск конфига» (версия 3)

**Колонки слева направо.** SQUARE — экран; DIAMOND — решение; ELLIPSE-флоу — ссылка на смежный флоу; ELLIPSE-круг — «Конец». Подписи — действия пользователя, развилки «исход: действие» по форме v2.

- колонка 8: SQUARE «Устройство создано»
- колонка 9: ELLIPSE «Флоу «Выдача файла»»

### 3.2. Стрелки (22), «источник → цель: подпись»
1. Флоу «Покупка доступа» → Оплата прошла: «возвращается в приложение»
2. Оплата прошла → Выбор платформы: «подключает устройство» (мимо экрана страны)
3. Главная → Страна: «открывает страну»
4. Страна → ◇Есть свободное место?: «добавляет устройство»
5. Страна → ◇Как заменяет устройство?: «меняет устройство»
6. ◇Есть свободное место? → Выбор платформы: «да: начинает подключение»

8. ◇Что делать с местом? → Флоу «Доп. слоты»: «докупает место»
9. ◇Что делать с местом? → Флоу «Удаление устройств»: «освобождает место»
10. ◇Что делать с местом? → Конец: «откладывает»
11. ◇Как заменяет устройство? → Флоу «Удаление устройств»: «удаляет старое, потом создаёт новое»
12. ◇Как заменяет устройство? → Флоу «Перевыпуск конфигурации»: «перевыпускает подключение»
13. Флоу «Удаление устройств» → Страна: «возвращается к стране»
14. Флоу «Перевыпуск конфигурации» → Устройство создано: «получает новое подключение»
15. Выбор платформы → Название устройства: «выбирает своё устройство»
16. Название устройства → Способ подключения: «выбирает имя»
17. Способ подключения → ◇Устройство создалось?: «создаёт устройство»
18. Способ подключения → ◇Устройство создалось? (нижняя дорожка): «выбирает свой способ и создаёт устройство»
19. ◇Устройство создалось? → Устройство создано: «да: получает готовое устройство»
20. ◇Устройство создалось? → Конец: «не создалось: уходит»
21. ◇Устройство создалось? → Конец: «не создалось: пишет в поддержку»
22. Устройство создано → Флоу «Выдача файла»: «переходит к подключению»

Стрелка 13 нарисована только для флоу «Удаление устройств» (в подсценарии автора «удалить старое и создать новое» после удаления нужно создание); возврат из «Доп. слоты» во вводных не описан и не рисуется.
