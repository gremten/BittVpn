# Заставка онбординга: HTML-прототип

Один автономный `index.html`: canvas 2D, без внешних зависимостей и без Lottie. Шрифты (подмножества Golos UI, Martian Grotesk, Nothing Font) и маска суши встроены в файл. Приложение `src/` прототип не затрагивает.

## Как открыть

- Открыть `index.html` в браузере, лучше в портретном окне примерно 390×844. Анимация запускается сама и длится 3 с; клавиша `R` проигрывает её заново.
- `?t=1500`: застывший кадр на 1500 мс.
- `?record=1`: режим записи. Время задаётся номером кадра и не зависит от реального. В консоли доступны `intro.renderFrame(i)` (шаг `1000/60` мс), `intro.renderAt(ms)`, `intro.frameCount()` и `intro.ready` (Promise загрузки шрифтов).
- `?record=1&autoplay=1`: покадровый прогон, по одному кадру на requestAnimationFrame.
- `prefers-reduced-motion: reduce`: сразу показывается финальный кадр.

## Где править

Все тайминги (мс), кривые (cubic-bezier), размеры, точки вида и координаты стран лежат в объекте `SETTINGS` вверху скрипта. Раскладка и её источники описаны в `research/intro_animation_timeline.md`, §0.

## Источники

- Логотип: геометрия сетки 9×9 и линия пульса замерены покадрово по `research/refs/intro_animation/ref1_logo_pulse.mp4`.
- Планета: проекция и перспектива взяты из образца particle-globe (код прислал автор). Финальный ракурс подогнан по `research/refs/intro_animation/ref5_final_view_author.png`. Маска суши — Natural Earth land 50m (пакет npm `world-atlas@2.0.2`, public domain), растеризована в 360×180.
- Кнопок пропуска заставки нет (решение автора). Нажатие кнопок «Продолжить» и «Пропустить» никуда не ведёт. Подзаголовок — временный lorem ipsum, настоящий текст напишет автор.
